# GU 2.1.2 — игровой интерфейс и журнал Android

Дата: 21 октября 2026 года. Ветка `feature/autonomous-learning-emulator`,
versionCode 36. Подход к навигации взят из MD.emu: игровой экран отдельно,
действия и настройки — в последовательных списках. Код и оформление собственные.

## Новый обычный интерфейс

Главное меню: продолжение игры, открытие ROM, недавние игры, действия с игрой,
экранное управление, клавиатура/геймпад, настройки, агент, лаборатория,
диагностика и сведения о приложении. При наличии native API доступен выход
с подтверждённым сохранением. Недоступные действия отключены.

Настройки открываются по одной категории: видео, звук, скорость, система,
альбомная ориентация и оформление. Импорт ROM начинается с выбора системы.
Библиотека использует существующие проверенные native копии картриджей.
Игровые слоты, превью и защита перезаписи сохранены. Прежние DOM-узлы и
обработчики используются повторно, данные пользователя не сбрасываются.

В игре видны только видео, крестовина/кнопки, Start/Mode/Select и небольшие
кнопки меню/ускорения. REC, AUTO, HUD, графики, хеши слоёв, библиотека,
ROM/import и отдельная большая кнопка запуска отсутствуют в обеих ориентациях.
Старые настройки full/monitors/game-details не возвращают эти панели.
Устаревшие переключатели панелей скрыты в обычных настройках, сохранённые
значения остаются совместимыми. Масштаб и пользовательские позиции управления,
левосторонний вариант, скрытие touch при геймпаде и редактор сохраняются.
Для новых профилей размер кнопок по умолчанию 100%; прежние размеры не меняются.

Открытие меню приостанавливает игру и освобождает ввод. Back/Escape возвращают
по иерархии; сначала отменяется назначение клавиши или редактирование управления.
Переход в уже приостановленные настройки не сбрасывает нейронное поколение.
Ручная игра после двух агентов ждёт сохранения обеих моделей и отключает их
управление. Ошибка сохранения остаётся явной; поздний ответ не открывает игру
поверх другой страницы. Ручные награды, SARSA и подробные Layer Sets доступны
через явно обозначенную лабораторию.

Фоновое восстановление ROM не запускает игру при просмотре списка/выборе системы.
Для запуска после выбора файла native передаёт отдельный признак `userOpened`;
для выбора из библиотеки используются явное намерение пользователя и точный
ROM/system. Устаревшее намерение после смены страницы или ошибки отбрасывается.

## Что показал присланный журнал

Исходный ZIP и полный разбор с идентификаторами остаются вне репозитория.
Ниже только агрегированные результаты; это один фрагмент, не общая приёмка.

- Около 4 минут 49 секунд, 864 целых события, потерь/ошибок записи 0.
- 15 успешных сохранений, 2 загрузки; аварий/ANR/завершения renderer в фрагменте нет.
- 8 console errors: `preventDefault()` при `touchstart` с `cancelable=false`.
  Добавлена проверка cancelable; игровой экран не прокручивается.
- 177 frontend save и 179 list Layer Sets, большинство с интервалами 0,4–0,8 с.
  Условие `automatic % 16 === 0` срабатывало при нуле, а обычный unknown boundary
  запускал дополнительное frontend сохранение. Нулевой/повторный milestone и
  эти дубли устранены. Изменённые веса, настоящее recovery, периодические и
  lifecycle checkpoint сохраняются. Полный FDB state принимается на каждом ACK.
- Native boundary по-прежнему подтверждает durable очистку traces. Полное
  устранение native I/O этим изменением не заявляется; причина редких просадок
  FPS одним журналом не установлена.
- Три отказа переключить Male CNS из-за безопасного бюджета памяти сохраняли
  прежнюю модель. Это отказ допуска, а не установленная авария/OOM.
- Sega преимущественно около 60 FPS; есть отдельные окна ниже. Native inference
  в разных окнах p50 156–307 мс, максимальный p95 428 мс. Это измеренные окна
  конкретного фрагмента, не гарантия задержки для всех игр/моделей.
- Звук выключен, frozen proofs отсутствуют. Синхронизация звука и функциональное
  обучение полных графов этим журналом не подтверждены. Один stale lifecycle ACK
  после возврата в foreground не объявляется потерянным сохранением.

- `git diff --check`: PASS.

Новый `console_navigation_ui_check` проходит реальные пользовательские пути на
настоящих NES/MD и IndexedDB: главный список/категории, picker → игра без графа,
фоновая загрузка без автозапуска, save/load и слоты, Back, клавиатурное назначение,
мультитач, оба положения экрана, сохранение весов и отсутствие дублирующих IDs.
Проверяются отказ dual save и поздний ответ после ухода со страницы. Native
picker/library/dual exit в этом браузерном тесте — явные protocol fixtures.
Прежние тесты сохраняют проверки ядер, самостоятельной игры, двух портов,
FDB, реального ввода/удержания и независимых сохранений.

Новый слой CSS проверен также на 360×640, 390×844, 480×280, 568×320, 844×390
и 1280×800. Скриншоты используют собственные диагностические ROM:
[главное меню](home.png), [настройки](options.png),
[портрет Sega](sega-portrait.png), [альбом Sega](sega-landscape.png).

## Что остаётся открытым

Новая версия ещё требует проверки на телефоне пользователя: физические touch,
Back и геймпад, системные панели, возвращение из фона, выбранные размеры/позиции,
память и звук в длительной игре. Браузерные проверки и старый журнал этого
не заменяют. Логгер и экспорт по-прежнему доступны в главном меню → Диагностика.

Полное ТЗ остаётся открытым: внешние проверенные игровые профили, полноценный
FDB replay/разнообразные задачи, возобновление парного сравнения, переносимые
backup/ремонт/ёмкость архивов, поведенческое Recovery, автоматические роли двух
агентов, маршрутизация/динамические кандидаты полных графов и измеренные
CPU/GPU оптимизации. Независимое приобретённое игровое поведение полного
коннектома пока не доказано. Эти задачи не списываются на ограничения модели.
