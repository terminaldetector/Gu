# Встроенный журнал устройства — 20 октября 2026

Рабочая копия `feature/autonomous-learning-emulator`, версия 2.1.1 (35).
Изменения ещё не опубликованы в main. Этот срез добавляет диагностику для
последующей сверки на Android пользователя, продолжая
[парную оценку и защищённый Best](../autonomous-paired-evaluation-2026-10-20/README.md).

## Реализовано

Постоянный ограниченный `DiagnosticJournal` и отдельный `DeviceLog` стартуют
из Application. Запись, таймер, контроль main/WebView heartbeat и экспорт
не зависят от нейронного worker. При отказе журнала видны ошибки/счётчики потерь,
игровой цикл не принимает их за ошибку FDB. Java uncaught handler сохраняет
событие, затем передаёт ошибку штатному Android handler.

`session-logger.js` собирает измеренные кадры и ограниченные окна timings,
связывает реальные операции save/load, регистрирует lifecycle, ошибки,
управление, нейронные границы и заметки. Native добавляет process CPU/RAM,
доступные датчики батареи, Android exit history и идентичность сборки.
Частые neural/audio/input события агрегируются, веса и игровые состояния
не сериализуются в обычный журнал.

Экспорт из настроек и быстрого меню создаёт ZIP с manifest, SHA256 каждого файла
и события, недавними метаданными эпизодов/проверок. Повреждённый хвост сохраняется
как свидетельство с явным invalidRows. Запись атомарная, квоты ограничены.
Нативный экран экспорта доступен при завершении renderer и ошибке запуска JS.
SAF сохраняет выбранный отчёт без доступа ко всему хранилищу.

Добавлен автономный разборщик ZIP с проверкой целостности, корреляцией операций,
раздельными успешными/ошибочными исходами и явными границами доказательства.
Инструкция: [журнал Android и дальнейшая сверка](../../DEVICE_DIAGNOSTICS_RU.md).

## Остатки ТЗ

Логгер и инструмент разбора реализованы; Android-измерения ещё предстоят.
Телефон есть у пользователя, в облачную среду он сейчас не подключён. Это не
причина останавливать разработку кодовых остатков.

Остаются проверенные внешние игровые feedback-профили; разнообразный игровой
протокол и полноценный FDB replay; возобновление прерванного парного сравнения;
продуктовый экспорт/импорт/ремонт/ёмкость архивов опыта; поведенческое восстановление
Current; эквивалентный жизненный цикл ролей для двух агентов; окончательная игровая
навигация; матрица портов полных графов; динамические кандидаты с сохранением
приобретённых путей; измеренная CPU/GPU оптимизация и релизная подготовка.
Диагностический ZIP не заменяет переносимый backup игровых/обученных данных.

Отдельно предстоят длительные прогоны на Android, звук, физическое управление,
фон/пересоздание, память/энергия и power-loss. Независимое улучшение поведения
полного коннектома на реальных играх ещё не доказано. Открытые инженерные задачи
не объявляются невозможными из-за ограничений модели.
