# E5 — Нейросетевой агент: Double DQN с настоящими градиентами

Статус: **построено и измерено. PASS на контролируемом семействе.** Агент меняет
поведение тогда и только тогда, когда внутренняя цепочка выдала **подтверждённую**
награду. Главный вывод не про обучение, а про то, **чему** здесь вообще можно
научиться: доступна только отрицательная награда, поэтому выучивается
**избегание**, и ничего больше.

- Модули: `app/src/main/assets/lab/agod-dqn.js` (новый, **ничем в продакшене не импортируется**)
- Проверка: `tools/agod_dqn_check.cjs`
- Данные: `logs/dqn_report.json`, лог `logs/agod_dqn_check.log`
- `Engine.java`, `FdbLearning.java`, `FdbGrowth.java`, форматы Layer Set — не затронуты

## 1. Запрещённый ярлык, против которого написан этот модуль

§1.3 запрещает «демонстрацию сети без обновления весов». Поэтому градиенты здесь
написаны руками и **проверяемы**: `loss` и `gradients` принимают один и тот же
батч, так что центральная конечная разность проверяет производную по **каждому**
параметру.

| Проверка механизма | Результат |
|---|---|
| аналитические градиенты против центральных конечных разностей | макс. ошибка **5.4e-11** по всем параметрам |
| цель Double DQN ≠ цель ванильного DQN | показано на расхождении: `double −1.5197` (онлайн-сеть выбрала действие 2), `vanilla −1.2109` (target-сеть взяла максимум) |
| детерминизм | один сид → побитово те же веса; другой сид → другие |
| checkpoint через JSON | возобновлённый прогон приходит в **те же** веса, что непрерывный (расхождение < 1e-12) |
| checkpoint чужой формы | отклонён |

E1 установил, что `DQN.train` в Stable-Baselines3 — ванильный DQN. Поэтому цель
Double DQN, которую требует NN-01, **написана, а не портирована**, и в модуле лежат
**обе** цели, чтобы расхождение можно было показать, а не принять на слово.

## 2. Награда берётся из внутренней цепочки, а не из оракула

Для каждого картриджа в том же прогоне заново проходится весь путь:

```
причинная привязка (E3) → типизация (E2) → индукция цели (E4)
      → реестр доказательств, holdout, promote → VERIFIED (AGOD-08)
      → брокер → скаляр для TD-цели
```

| Метрика цепочки | Результат |
|---|---|
| «штрафующая» кнопка найдена без оракула | **42 / 42** прогонов |
| найденный ресурс — это действительно жизни | **42 / 42** |
| цель доведена до `VERIFIED` внутренними доказательствами | 7 / 7 картриджей |

Оракул открывается только для подсчёта этих двух строк.

### 2.1. Побочный результат: ограничение C3.3 сузилось

E4 получал область «игровых эффектов» **извне** (от чекера, из оракула), потому что
служебное эхо ввода отделить не удавалось. Здесь оно отделено **изнутри**: адрес,
который меняется только пока кнопка удерживается, и возвращается к прежнему значению
после отпускания, — это проводка ввода; эффект, **сохраняющийся после отпускания**,
принадлежит игровому состоянию. Этого достаточно, чтобы цепочка прошла без оракула
на всех 7 картриджах. Общего решения это не даёт: эхо, реализованное иначе
(с защёлкой), так не отделится.

## 3. `UNKNOWN` не превращается в ноль

Транзакция, по которой брокер вернул `UNKNOWN`, **вообще не кладётся в replay**.
`UNKNOWN` — это отсутствие доказательства, а не награда 0, и в TD-цель оно не
попадает никогда. За обучение (400 шагов) брокер выдал 70–84 выплаты и 426–429
отказов `UNKNOWN`; в replay попали только выплаты.

## 4. Поведение: обученный против необученного и против случайного

Замороженная оценка: 60 шагов, ε = 0, обучение выключено.

| | штрафуемое действие | потеряно жизней |
|---|---:|---:|
| обученный агент | **0.000** | **0** |
| необученный (та же инициализация, цель не `VERIFIED`) | 0.508 | 13.3 |
| случайная политика (ε = 1, измерено) | 0.361 | 15.3 |

**Честная оговорка про выборку.** Контроль не обновляет веса, а признаки состояния
на всех картриджах одинаковы, поэтому необученная политика **не зависит от
картриджа**: её эффективный размер выборки — 6 сидов агента, а не 42 прогона.
По сидам:

| сид агента | необученная политика | потеряно жизней | после обучения |
|---|---|---:|---|
| 11 | штрафуемое действие **каждый** шаг (60/60) | 26 | 0 |
| 29 | штрафуемое действие **каждый** шаг | 26 | 0 |
| 53 | штрафуемое действие **каждый** шаг | 26 | 0 |
| 37 | штрафуемое действие 3/60 | 2 | 0 |
| 71 | не выбирает штрафуемое | 0 | 0 |
| 97 | не выбирает штрафуемое | 0 | 0 |

Информативны именно 4 сида из 6, где необученная политика выбирала штрафуемое
действие: **28 / 28 таких прогонов** после обучения его не выбирают, обратных случаев
**0**.

### 4.1. Более сильное утверждение, не зависящее от сида

Сравнение частот зависит от того, куда случайно попал argmax при инициализации.
Устойчивее смотреть на сами Q-значения в состоянии «ресурс полон»:

| | результат |
|---|---|
| прогоны, где Q(штрафуемое) — **минимум** из трёх | **42 / 42** |
| прогоны, где Q(штрафуемое) < 0 | 35 / 42 |

Это уже не про то, какое действие победило, а про то, что агент **выучил цену**
штрафуемого действия на каждом картридже и каждом сиде.

## 5. Асимметрия полярности видна прямо в поведении

Среди двух неоштрафованных действий (ничего не делать / нажимать кнопку, растящую
счёт) обученные агенты распределились **21 / 21**.

Это не шум реализации, а прямое следствие результата E4: `POSITIVE` изнутри
эмулятора недоказуема, поэтому за рост счёта награды нет, и агенту **безразлично**,
набирать очки или стоять на месте. Он научился не умирать и ровно ничему больше.
Чтобы агент хотел чего-то, а не только избегал, нужен внешний источник истины —
независимый оракул §11.2 или разметка человеком. **Ни один вывод об «игровом
улучшении» из E5 не следует и не делается.**

## 6. Чего E5 НЕ сделал

1. **Это не игра, а трёхдейственная среда на контролируемом картридже.** Признаки —
   нормированный ресурс, флаг исчерпания и one-hot предыдущего действия. Пикселей,
   свёрток, кадровых стеков нет.
2. **Оптимальная политика проста.** «Не нажимай штрафуемую кнопку» — короткий ответ,
   и то, что DQN его находит, доказывает корректность механизма, а не способность
   решать игры.
3. **Сравнения с опубликованным baseline нет.** Ни SB3, ни rcheevos ничего здесь не
   запускали; упомянутый ванильный DQN использован только как контрпример цели.
4. **Горизонт короткий**: 400 шагов обучения, 60 шагов оценки, γ = 0.95, скрытый
   слой 24, Adam. Подбора гиперпараметров не делалось: взяты одни значения и
   оставлены.
5. **Blind-корпус §11.1 и независимый оракул §11.2 не существуют**; всё измерено на
   том же синтетическом семействе.
6. **Android не затронут.** Стоимость обучения на устройстве не измерялась; с FDB,
   `Engine` и форматами Layer Set этот модуль не связан никак.
7. Внутренней мотивации (novelty) агент не использует, хотя канал для неё в брокере
   есть.

## 7. Влияние на гейты

- **G4 (Neural)** — **закрыт на контролируемом семействе**: настоящие обновления
  весов (проверенные конечными разностями), цель Double DQN, replay, target-сеть с
  синхронизацией, детерминизм, checkpoint. Для реальных игр и Android — открыт.
- **G5 (Behavior)** — остаётся **OPEN**: замороженная оценка и контроль появились, но
  blind-корпуса и независимого оракула нет, а измеренное поведение — избегание на
  синтетическом картридже.
- Остальные — без изменений.
