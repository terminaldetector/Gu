# Male CNS / импорт синтетических графов: аудит 14 октября 2026

База: `37ec493fa951afe8b1147714885403d0a8641f36`, ветка `v2/gmode-fdb-gpu`.
Проверены исходники; установленный пользовательский APK и физический телефон не проверялись.

## Итог по Male CNS

Прямого использования одного файла для FlyWire и Male CNS не обнаружено.

| Узел | FlyWire | Male CNS |
| --- | --- | --- |
| ID | flywire-v783 | male-cns-v1.0 |
| Граф APK | brain.fly.gz / brain.fly | male-cns.fly.gz / male-cns.fly |
| Паспорт | brain.fly.json | male-cns.fly.json |
| Порты | Experiment.automatic | default_inputs/default_outputs из паспорта |
| Сохранения solo | платформа + SHA ROM + SHA графа | тот же алгоритм ключа, другой SHA графа |
| Сохранения пары | платформа + SHA ROM + SHA графа + P1/P2 | дополнительно проверяется modelId внутри checkpoint |

Путь подключения: model-ui.js → selectConnectome → ConnectomeStore.candidate → Graph.read + SHA → ConnectomeStore.ports → отдельные Engine / FdbLearning / GraphDelta. В парном режиме DualAgentContext создаёт независимые engine, FDB, seed и историю; общим может быть только неизменяемый Graph при выборе одной модели для обоих игроков. Один каталог layer-sets не означает общие веса: файлы имеют отдельные UUID, проверяется принадлежность ROM/графу/слоту.

Male CNS использует 16 ol_sensory и 12 vnc_motor ID, выбираемых детерминированно конвертером; NES/GB берут первые 8 выходов. ID должны существовать в графе, не дублироваться и не пересекаться. Это техническое отображение, а не доказанная биологическая семантика игровых кнопок. Конвертер обнуляет неизвестные/модуляторные знаки: анатомическое ребро может не проводить ток. Наличие модели в меню и числа нейронов недостаточно для доказательства полезного сигнала и игрового обучения.

## Найдено и исправлено

1. **Несверенный текущий кэш.** GraphCache.loadNamed возвращал current по совпадению ID без проверки ожидаемого SHA. Теперь все попадания проходят findNamed(id, expectedSha), включая current; несовпадение заставляет перечитать и проверить источник. Ошибка сохраняет прежнюю модель.
2. **Неверное имя в диагностике.** LabDiagnostics.describe использовал глобальный GraphCache.modelId, даже если переданный Graph принадлежал другой сети/экрану. Теперь определяется идентичность самого объекта. Незарегистрированный граф помечается unregistered, а не объявляется FlyWire/Male CNS.
3. **Раздельное чтение графа и глобального ID.** NesLabActivity.loadGraph получал граф, затем читал глобальный ID. Теперь выбранный ID фиксируется до загрузки и используется для графа и портов вместе.
4. **Нет JSON-импорта W0.** Добавлен тип fly-synthetic-graph v1 (CSR float32), отдельный от fly-layer-set. Через ту же кнопку «Импорт JSON · набор / граф» он проходит сохранение текущего опыта, нативную валидацию, подготовку Engine и установку. ROM не меняется, обучение само не включается.
5. **Возврат к импортированной сети.** Пункт Imported был доступен только как информационная отметка текущей модели. Теперь сохранённую импортированную сеть можно выбрать после переключения на FlyWire/Male CNS.
6. **Хранение синтетических сетей.** JSON-графы сохраняются в synthetic-graphs/<SHA>.fly. Указатель на импортированный граф и выбранная модель фиксируются одной записью preferences после записи файла. Ошибка до фиксации не меняет выбор. Старый бинарный импорт connectome.fly сохранён, при нём сбрасывается указатель на синтетический файл.

## Три JSON

examples/synthetic/01-simple.json: 128 узлов, 1 398 связей.
examples/synthetic/02-medium.json: 512 узлов, 5 943 связи.
examples/synthetic/03-complex.json: 2 048 узлов, 29 926 связей.

Это прежние проверенные синтетические резервуары в точном JSON-представлении. Масштабированные величины весов исходно взяты из выборки FlyWire; это **не** синтетическая реконструкция Male CNS и не надстройка поверх его нейронов. Импорт выбирает отдельную сеть; исходные Male CNS/FlyWire остаются в APK. Для FDB-надстройки над конкретным Male CNS нужен другой артефакт с его реальными ID и SHA, а не эти локальные ID 1…N.

Импорт: новая сборка → «Модели» → «Импорт JSON · набор / граф» → выбранный JSON. Затем загрузить ROM, создать/выбрать совместимый Layer Set, включить FDB и демонстрации/награду. Старый APK 2.0.0 эти JSON как графы не поддерживает. Имена файлов не определяют игровую политику; опыт принадлежит отдельному Layer Set конкретной игры и графа.

## Проверки и оставшиеся ограничения

Локально прошли GraphIdentityCheck (разные модели, неверный SHA кэша, сохранение предыдущего графа при ошибке), SyntheticGraphCheck для всех трёх файлов (SHA, бинарный round-trip, динамика Engine, повреждённые поля/веса/CSR и лимит памяти), synthetic_import_check (сохранение до установки, отказ сохранения, повторный запрос, старый bridge, успех/ошибка), существующие model_ui_check, dual_ui_check, dual_routing_check, layer_sets_check. Проверки включены в tools/check.sh.

Полный runtime-прогон Male CNS, его прохождение игр, энергопотребление на Android, GPU и реальный системный file picker в этой сессии не проверены. Перед распространением нужен APK с успешным Android CI и тест на телефоне. Для Male CNS остаётся измерить выходную активность и задержку на одинаковых кадрах относительно FlyWire; равенство игровых результатов не следует из корректности путей.

Синтетический импорт пока относится к одиночной активной сети; отдельного выбора произвольных импортированных графов в каталоге пары не добавлено. Шаблон не является обученным ботом. FDB/Layer Set сохраняют приобретённые параметры, а не весь мгновенный LIF-state.
