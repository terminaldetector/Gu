Модели и игроки

P1 + P2 · два независимых коннектома

Две реальные нейронные модели управляют разными портами одного ROM. Общий экран и игровые кадры; независимые CPU-движки, seed, FDB и сохранённые слои. Внешний SARSA и показ человеком остаются в одиночном контуре ниже.

Два порта недоступны. GB link не реализован; две сети не запускаются.

Профиль P1 используется для обоих игроков. Это командный сигнал, а не доказательство индивидуального вклада: одна сеть может получать награду за успех другой. Раздельные ручные кнопки отключены.

Ручное вмешательство исключает credit затронутого порта. RAM-адреса задаются для конкретной игры. Eval не меняет веса; Train обучает при включённом FDB. GPU для двух сетей пока не подключён. Настройки портов восстанавливаются для своего ROM; запуск после перезапуска всегда ручной.

Механизм обучения и стартовые параметры

Нейронное управление выбирает игровые действия по активности выходов коннектома. В Automode награда обновляет временные следы Wexo; внешний SARSA не обучается. Сначала подключите FDB. В проверке действия детерминированы, веса и счётчики заморожены.

Задаёт исходный уклон выбора кнопок и параметры SARSA. Приобретённые веса не заменяет. Для нейронного FDB эта эвристика не используется.

При ускорении звук приглушён. Достигнутая скорость зависит от устройства и расчёта модели.

Следующий этап · обучение FDB

W₀ — исходный коннектом, ΔW — явно заданные дельты, Wexo — приобретённые связи. Показ человека закрепляет вход → кнопку. В нейронном Automode временной след выбранного действия получает награду: связи усиливаются, ослабевают и при накоплении отрицательного вклада удаляются. Рост ограничен. SARSA выбирается отдельно; его награда не меняет случайные связи Wexo. Сохраните именованный Layer Set для долговременного обучения. Рост сам по себе не доказывает освоение игры.

Исследовательские настройки · профиль, RAM, SARSA, эпизоды

RAM: награда = изменение значения × множитель. Адрес и формат счёта задаются для конкретной игры. Переполнение учитывается только при включённой опции.

Профиль внешней игры

Изменение действий останавливает опыт; веса общих действий сохраняются. Доступ к Start/Select определяется режимом выше. Заблокированные действия остаются в файле весов, но не выбираются политикой. Для Sega C остаётся игровой кнопкой.

Старт: перезапуск ROM с начала.

Экспорт включает профиль, стартовый снимок консоли, веса подражания, SARSA и последние примеры человека. RAM победы/смерти не определяется автоматически. PAL/Dendy тайминг и battery .sav в этом интерфейсе не реализованы.

В непрерывной игре граница обучения сохраняет текущий кадр и состояние сети. Автоперезапуск ROM действует только в эпизодических опытах.

Диагностическая награда и координаты читают RAM собственного ROM — это явно заданная задача, не самостоятельное понимание игры. В проверке веса адаптера и FDB заморожены. В Automode ручное вмешательство исключается из обновлений по награде. В показе состояние фиксируется до действия P1; образец принимается после успешных игровых кадров. Удержания собираются в блоки около 0.1 секунды и завершаются при смене кнопок. Start/Select/Mode пропускаются, если доступ модели к ним заблокирован.
