Обучение игрового выхода

SARSA(λ) обучает небольшой адаптер кнопок по картинке и 8 выходам сети. Исходные связи коннектома остаются фиксированными. Обучение требует замкнутого контура и пошагового времени.

RAM: награда = изменение значения × множитель. Адрес и формат счёта задаются для конкретной игры. Переполнение учитывается только при включённой опции.

Профиль внешней игры

Изменение действий останавливает опыт; веса общих действий сохраняются. Доступ к Start/Select определяется режимом выше. Заблокированные действия остаются в файле весов, но не выбираются политикой. Для Sega C остаётся игровой кнопкой.
