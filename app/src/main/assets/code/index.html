Локальные JS-эксперименты над коннектомом. Код и модули выполняются в отдельном Worker без доступа к Android, сети и файлам. JS / ZIP-модули — не установка APK или Linux-программ. Переключение в игровой режим останавливает скрипт.

Готов к запуску. Коннектом загружается в фоне.
API и ограничения
const info = await fly.info(); // ids: строковые ID, neurons, edges
const result = await fly.run({seed:1, reset:true, steps:[
 {ms:20, inputs:[{id:info.ids[0], hz:150}], outputs:[info.ids[0]]}
]});
fly.log(result);
fly.plot("Hz", [0, 10, 20]); // значения по порядку, без интерполяции
await fly.sleep(100);
const tools = require("signal"); // установленный ZIP-модуль
fly.log(tools.mean([1,2,3]));

64 API-вызова за запуск; каждый инференс до 10 секунд биологического времени. Скрипт ограничен 30 секундами реального времени. «Стоп» завершает Worker и отменяет текущий расчёт. reset:false переносит состояние сети между вызовами; новый проект сам по себе сеть не сбрасывает. Генератор Math.random не воспроизводим: используйте собственный seeded RNG. Модель LIF, биологическая эквивалентность не подтверждена.

Модули CommonJS: module.exports / exports / require. ZIP содержит module.json: {"id":"signal","name":"Signal tools","api":1,"entry":"index.js"}. Только JS/JSON/TXT/MD, до 64 файлов и 1 МиБ; без нативных библиотек и установки зависимостей из сети. Локальные зависимости — require('./file.js'), внешние — require('module-id'). Модули из проекта активируются только при запуске.

Проект включает код и полный набор модулей. Снимок нейронного состояния не включён. Удаление модуля не изменяет ранее сохранённые проекты.
